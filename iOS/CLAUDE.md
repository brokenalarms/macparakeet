# CLAUDE.md — iOS

MacParakeet for iPhone: local Parakeet dictation via a launcher keyboard. Dictation only; per-device data; no sync; no LLM text features.

## Hard rule

**Never modify anything outside `iOS/`.** The Mac app, its spec, docs, tests, and build scripts must not know the iOS app exists. iOS consumes existing Mac code read-only. If shared code doesn't build for iOS, exclude it in `project.yml` or add a replacement in `CoreReplacements/` — never edit `../Sources`. Gate: `git diff --stat main -- . ':!iOS'` is empty.

## Build

The Xcode project is generated by XcodeGen from `project.yml` (`.xcodeproj` is gitignored).

```bash
brew install xcodegen   # once
make -C iOS project     # generate .xcodeproj
make -C iOS build       # iOS Simulator build
make -C iOS test        # iOS tests
swift test              # Mac suite, must stay green
```
