# CLAUDE.md — iOS

MacParakeet for iPhone: local Parakeet dictation via a launcher keyboard. Dictation only; per-device data; no sync; no LLM text features; no telemetry. The English model is bundled; the only network access is the optional multilingual model download.

## Hard rule

**Never modify anything outside `iOS/`.** The Mac app, its spec, docs, tests, and build scripts must not know the iOS app exists. iOS consumes existing Mac code read-only. If shared code doesn't build for iOS, exclude it in `project.yml` or add a replacement in `CoreReplacements/` — never edit `../Sources`. Gate: `git diff --stat main -- . ':!iOS'` is empty.

## Build

The Xcode project is generated by XcodeGen from `project.yml` (`.xcodeproj` is gitignored).

```bash
brew install xcodegen   # once
make -C iOS models      # fetch the bundled English model (~400 MB, once; `project` runs it)
make -C iOS project     # generate .xcodeproj
make -C iOS build       # iOS Simulator build
make -C iOS test        # iOS tests
swift test              # Mac suite, must stay green
```

To sign for a device, create `Config/Local.xcconfig` (gitignored) with your `DEVELOPMENT_TEAM`, a `BUNDLE_ID_PREFIX` you own, and a matching `APP_GROUP_ID`.

## Gotchas

- **GRDB matches the Mac pin (7.10.0); FluidAudio deliberately doesn't** (iOS 0.17.7, Mac 0.12.5). The bundled 110M model needs 0.17.x. The Mac `STTClient` doesn't compile against it, so it's excluded and `CoreReplacements/MobileSTTClient.swift` replaces it. If another shared file starts using FluidAudio, it needs the same treatment.
- **The bundled model is not in git.** `Models/` is gitignored and filled by `scripts/fetch-bundled-model.sh`. Building from Xcode without running `make -C iOS models` first fails on the missing resource folder.
- **If a shared file starts referencing an excluded one, add it to the `excludes` list** when it's only used by excluded code (as with `LLMClient` and `SpeakerMerger`). Otherwise add a replacement in `CoreReplacements/`.
- **The test target is unhosted.** It compiles `Shared/` and the testable `App/` files directly. When a new `App/` file needs tests, add it to `MacParakeetiOSTests.sources`.
- **Never compile network code into iOS.** Telemetry, crash reporting, feedback, Discover, and licensing stay in `excludes`. `CoreReplacements/Telemetry.swift` is a no-op facade, so don't call `Telemetry.configure` or wire a `TelemetryService`.
- **The database lives in the app's private container, not the App Group.** Only `ipc/*.json` is shared with the keyboard.
